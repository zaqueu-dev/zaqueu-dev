## 📌 Featured Projects

### 🔥 Lowdeep – Open Source AI SDK
[![Repo](https://img.shields.io/badge/GitHub-archydre/lowdeep-0D1117?style=for-the-badge&logo=github)](https://github.com/archydre/lowdeep)

**Fluid, resilient, 100% Type-Safe AI SDK** with a Self-Healing mechanism that uses Zod to automatically validate and correct LLM responses in real time.

- ✅ Provider-agnostic (works with any OpenAI-compatible API)
- ✅ Enables low-cost, high-reliability AI features in production
- ✅ Used as a learning tool for AI integration patterns

### ⚛️ Isthor – Reactive State Management
[![Repo](https://img.shields.io/badge/GitHub-archydre/isthor-0D1117?style=for-the-badge&logo=github)](https://github.com/archydre/isthor)

**Minimalist reactive state management for React** using Proxies. Simpler than Zustand, allows direct object manipulation with Zod schema validation.

- ✅ Reduces boilerplate and improves type safety
- ✅ Experimental Proxy-based reactivity

### 🤖 AI Token Chatbot
**Chatbot platform integrating multiple LLMs** (via DeepInfra) with a credit-based monetization system using USDC on Base network.

- ✅ Chat history encryption with Turso + AI SDK
- ✅ End-to-end crypto payment flow demonstration

### 📖 Lou Reading App
**Reading application for Project Gutenberg works** with embedded EPUB reader, annotations, highlights, web dictionary, and reading progress sync.

- ✅ Progress sync backend with Turso + Cloudflare Workers
- ✅ Modern, responsive interface – planned PWA publication
